# Pena changelog

Pena's own releases, by Pena version. Installed apps show a version's section in the Software Update window, and its GitHub release carries the same notes. Each Pena release names the OpenPencil version it is built on; OpenPencil's own changes are in the root `CHANGELOG.md`.

## 1.0.2

Built on OpenPencil 0.17.0-beta.1.

- Keep opened documents in their tabs while a slow canvas finishes drawing.
- Open and switch pages in large design files with less work by loading only the component sets the page uses.

## 1.0.1

Built on OpenPencil 0.17.0-beta.1.

- Pena Desktop connects to self-hosted Cloud servers whose HTTPS certificate is trusted in macOS Keychain.

## 1.0.0

The first Pena release, built on OpenPencil 0.17.0-beta.1.

- Pena updates itself: it checks for a new version when it opens and from **Pena → Check for Updates…**, downloads and verifies the update, and installs it on restart.
